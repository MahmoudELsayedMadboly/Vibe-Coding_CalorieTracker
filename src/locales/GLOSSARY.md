# Arabic glossary

Modern Standard Arabic. Use these terms everywhere so the app reads
consistently. Change a term here first, then in `ar.json`.

Conventions: Western digits (0–9), dates in `ar-SA` with the Gregorian
calendar, units come from the translations, user data (food names, plans,
notes, chat) is never translated.
